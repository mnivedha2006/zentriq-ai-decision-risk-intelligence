# Zentriq AI — Decision Risk & Decision Debt Intelligence System

AI-powered decision risk intelligence system that detects decision debt, prioritizes risky business decisions, and provides actionable recommendations.

## Core Architecture
- **Document Processing**: PyMuPDF & python-docx
- **AI Extraction**: Google Gemini API
- **Risk Calculation**: Deterministic Decision Debt Engine (0-100 Score)
- **Database**: SQLite
- **UI**: Streamlit & Plotly
